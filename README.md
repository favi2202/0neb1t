# 0neb1t — School 21 Cybersecurity

This repository organizes work for the School 21 cybersecurity track (CbS1–CbS18).

The official task text remains on the School 21 platform. This repository contains original study notes, plans, safe lab guidance, deliverable checklists, and—after verification—the student's own project artifacts.

## Rules

- Complete School 21 submissions in the assigned GitLab repository and its required `develop` branch.
- Work only in `src` when the project requires it.
- Preserve exact filenames from the official task.
- Never fabricate screenshots, packet captures, command output, flags, or test results.
- Keep private keys, credentials, personal information, real phishing data, and unauthorized scan results out of this public repository.
- Network attack exercises must stay inside an isolated, authorized lab.
- A task is not considered complete until its result is independently verified.
