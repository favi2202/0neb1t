# Preparation-first workflow

Use this workflow whenever an official School 21 repository, source file, packet capture, VM image, license, or lab environment is not yet available.

## What can be completed now

1. Extract every official requirement and exact filename.
2. Separate supplied inputs from deliverables.
3. Solve theory and calculations that do not depend on hidden files.
4. Prepare original explanations, commands, folder plans, answer templates, verification checks, likely reviewer questions, and troubleshooting notes.
5. State the expected result, but label it as expected rather than observed.
6. Record what evidence must be captured later.

## What must remain pending

- Opening or analyzing a source file that has not been supplied
- Generating genuine packet captures or screenshots
- Confirming software or image installation
- Claiming a configuration, command, script, or test succeeded
- Recovering a challenge-specific flag without the challenge input
- Marking the official GitLab task complete

## Status labels

- **Prepared:** theory/runbook/template is ready.
- **Execution pending:** an official input or environment is missing.
- **Verification pending:** work was performed but evidence has not been checked.
- **Ready for review:** required artifact and verification evidence are confirmed.
- **Submitted/Passed:** only after the user confirms the official result.

This keeps progress moving without fabricating laboratory evidence.
